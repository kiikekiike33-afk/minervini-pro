# ミネルヴィニ・オニール流 成長株スクリーニング＆ダッシュボード (Minervini Pro)

日本株（東証全上場銘柄 約3,700社）を対象に、著名投資家ウィリアム・オニール（William J. O'Neil）およびマーク・ミネルヴィニ（Mark Minervini）の成長株投資手法（第2ステージ・VCP・ブレイクアウト）に基づき、真のモメンタムと健全なファンダメンタルズを兼ね備えた優良銘柄を全自動でスクリーニング・分析するシステムです。

---

## 🎯 主な機能・特徴

1. **東証全銘柄の高精度スクリーニング**
   - 日本取引所グループ（JPX）の最新銘柄リストからETF・REIT等を除いた全上場株式を毎日自動取得。
   - 3段階のテクニカル分析＋ファンダメンタルズ健全性フィルタで、3,700銘柄から数件〜十数件の「初動ブレイク銘柄」を厳選。

2. **抽出ロジック（S・A評価）**
   - **基本トレンド**: 株価 > 200日移動平均線（上向き推移）。短期・長期の過度な上方乖離（SMA50から+20%以上、SMA200から+40%以上）を除外して伸びきった銘柄を排除。
   - **3ヶ月以上ぶりの新高値**: 過去1年間の最高値が「3ヶ月（60営業日）以上前」に形成され、直近5日間でその高値を突破した「長期間の揉み合い・調整を終えた初動銘柄」を検出。
   - **大口資金流入（出来高）**: ブレイクアウト時の出来高が過去50日平均の **1.5倍以上**（2.0倍以上は大商いサージ）。
   - **流動性確保**: 20日平均売買代金 **3億円以上**。
   - **ファンダメンタルズ健全性**: **今期予想純利益（Forward EPS）が黒字**（赤字企業を除外）、かつ **直近決算の営業キャッシュフローがプラス**（本業で現金を稼げている企業のみ抽出）。

3. **直感的なWebダッシュボード（Streamlit）**
   - Glassmorphism（すりガラス）調のダークモードデザイン。
   - **マネックス銘柄スカウター連携**: 銘柄名をクリックすると、当該銘柄のマネックス証券「銘柄スカウター（財務詳細）」へダイレクト遷移。
   - **インタラクティブ・チャート**: 移動平均線（20日/50日/150日/200日）と出来高、52週高値ラインを表示。
   - **Gemini AI カタリスト分析**: Google Gemini APIと連携し、銘柄の急騰理由・カタリスト・リスク要因を要約レポート化。

## 🛠️ セットアップと実行手順

### 1. 依存ライブラリのインストール

Python 3.10以上がインストールされた環境で以下を実行します:

```bash
cd code
pip install -r requirements.txt
```

### 2. ローカルでの起動

```bash
cd code
streamlit run app.py
```
ブラウザが立ち上がり、`http://localhost:8501`（または指定ポート）でダッシュボードが表示されます。

### 3. スマートフォン等からの利用（Streamlit Community Cloud）

1. このリポジトリをご自身のGitHubアカウントにプッシュ（公開または非公開）。
2. [Streamlit Community Cloud](https://streamlit.io/cloud) にアクセスし、GitHubアカウントでログイン。
3. 「New app」から本リポジトリを選択し、メインファイルに `code/app.py` を指定して「Deploy」をクリック。
4. 発行されたURL（`https://xxx.streamlit.app`）をスマートフォンのブラウザでブックマークするか、「ホーム画面に追加」することで、いつでもスマホから確認可能です。
