# ミネルヴィニ・オニール流 成長株スクリーニング＆ダッシュボード (Minervini Pro)

日本株（東証全銘柄）から、オニール＆ミネルヴィニ流の「S・A評価」成長株（VCP、3ヶ月以上ぶりの新高値ブレイク、出来高急増、黒字・営業CFプラス）を自動抽出・可視化するWebダッシュボードです。

詳細な機能設計・抽出ロジック・運用方法については [docs/README.md](docs/README.md) をご覧ください。

## クイックスタート

```bash
cd code
pip install -r requirements.txt
streamlit run app.py
```
